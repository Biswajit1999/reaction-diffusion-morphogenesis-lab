What is happening?
This model has two chemicals. Chemical A feeds the system. Chemical B grows by consuming A, then both diffuse. The surprise is that these simple local rules can generate global structure.
Model:
∂A/∂t = Dₐ∇²A − AB² + F(1−A)
∂B/∂t = Dᵦ∇²B + AB² − (k+F)B
Why forkable?
One file. No framework. No build step. A student can edit the equations; a researcher can add anisotropic diffusion, noise, parameter sweeps or image export.
